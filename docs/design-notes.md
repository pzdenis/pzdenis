# Design notes

- **Struktur:** `README.md` ist die Profilseite. `assets/header.svg` enthält das freigegebene Logo, `assets/tiles/` die vier Fokus-Kacheln. `assets/header-preview.png` und `assets/tiles-preview.png` sind lokale Ansichtskopien. Keine Build-Abhängigkeiten; ein zusätzlicher Divider ist für dieses Layout nicht nötig.
- **Farben:** Indigo `#2E2E40`, helle Schrift `#B6D98A`, Details `#414653`. Die Logo-Bänder reichen von `#C5D8A5` über `#B5D98A`, `#A5D96A` und `#84A75C` bis `#566C40`. Hexwerte direkt in den SVGs ändern; Header und Kacheln gemeinsam pflegen.
- **Header:** Das freigegebene Design beibehalten. `pzdenis` besteht aus sieben kommentierten Pfaden, nicht aus einer Schrift. Änderungen am Namen erfordern neue Glyphenpfade. Größe und Position steuert die äußere Gruppe; den Untertitel im einzigen `<text>`-Element bearbeiten. Doppelte Gradient-Stops erzeugen harte Farbbänder.
- **Kacheln:** Einheitlich 600 × 184. Titel, Untertitel und Icon-Pfad direkt bearbeiten. Für neue Kacheln eine vorhandene SVG kopieren, `<title>`, `<desc>` und Texte aktualisieren und ein Bild samt Alt-Text in der README ergänzen.
- **Links:** Repository-URLs und Beschreibungen stehen in der README-Tabelle. Eurex-Beschreibung und Python sind anhand der öffentlichen Repository-Seite geprüft. Die übrigen drei Seiten waren bei der Prüfung nicht abrufbar; Beschreibungen sind bewusst thematisch gehalten, Technologien nicht behauptet. Ihre Erreichbarkeit und Angaben vor Veröffentlichung manuell prüfen.
- **GitHub:** Nur relative Bilder, Markdown und einfache HTML-Bildelemente verwenden. Kein JavaScript, externes CSS oder externe Schriftdateien. Das Logo ist schriftunabhängig; Untertitel und Kacheltexte verwenden lokale Monospace-Fallbacks und können je nach Renderer leicht abweichen. Zwei Kacheln pro Zeile nutzen jeweils 49 % Breite; auf schmalen Displays die Lesbarkeit prüfen. Alt-Texte bleiben auch ohne Bilder verständlich.
- **Vorschau:** Mit installiertem ImageMagick etwa `magick -background none assets/header.svg assets/header-preview.png` ausführen. SVGs sind die Quelldateien; PNGs nach Änderungen neu erzeugen. Abschließend auf GitHub Desktop/Mobil, beide Themes, Schrift-Fallbacks und alle Links prüfen. Das Profil erscheint über ein öffentliches Repository namens `pzdenis` im Account `pzdenis` mit einer README im Repository-Stamm.
